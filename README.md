# Книжный блокнот

Приложение задеплоено [здесь](https://lisa-lpt.github.io/otus-react/)

## Описание

В этом приложении пользователь сначала попадает на домашнюю страничку с описанием функционала, а потом может перейти в каталог книг и найти нужную книгу по названию. Каждую книгу можно добавить в список для чтения позже или перейти на ее страницу с дополнительной информацией.

Аналогично со страницей каталога авторов. В каталоге можно искать авторов по именам и переходить на их страничку, где показывается список книг, которые они написали.

В списке для чтения позже добавляются выбранные книги и подсчитывается их количество.

## Технологии

Это SPA-приложение. Стек: react, typescript, react router, redux toolkit, mantine, vite, eslint, prettier, vitest, react testing library.

## Команды

`npm run dev` - запуск dev-режима

`npm run build` - билд проекта

`npm run preview` - превью билда

`npm run lint` - линтер

`npm run test` - тесты
